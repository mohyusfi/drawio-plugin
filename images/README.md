# Image Assets

Icons and cover artwork are generated using internal image generation tools and post-processed via browser Canvas for resizing and WebP encoding. The icon is original artwork and does not use the official draw.io logo. The cover is a promotional illustration, not a feature screenshot.

| File | Purpose | Dimensions |
| --- | --- | --- |
| icon.png | Marketplace icon | 256×256 |
| tab-icon.png | Tab and "New File" menu icon | 128×128 |
| cover.webp | Marketplace cover | 1600×1000 |
| editing-light.png | Real editor screenshot (Light theme) | 1600×1000 |
| editing-dark.png | Real editor screenshot (Dark theme) | 1600×1000 |
| editing-selection.png | Real editor screenshot (Selected node) | 1600×1000 |

Screenshots are captured by `build/preview.mjs` running the genuine editor within the same browser sandbox and CSP environment as Orca Desktop. `editor-dark.png` is retained as a legacy development preview.
